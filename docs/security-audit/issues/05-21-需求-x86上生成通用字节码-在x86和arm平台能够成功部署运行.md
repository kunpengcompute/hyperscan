# [需求]: x86上生成通用字节码，在x86和arm平台能够成功部署运行

- Remote: https://gitcode.com/boostkit/hyperscan/issues/21
- Issue Type: 需求
- Domain: boost-core
- Source: local audit / GitCode issue sync

## Details

感谢提出新需求。

### 【需求背景】
            
x86上实现通用字节码功能，使能规则编译结果的跨平台部署运行能力。
### 【需求描述】
            
1、功能

   1）hyperscan的通用字节码功能，实现规则编译结果的跨平台部署运行。

2、 规格/参数

1）在x86上编译规则集并序列化，并将序列化结果部署在x86和arm平台，能够成功反序列化并执行匹配。

2）在x86和arm上对相同规则集生成的通用字节码保持一致。

3）在x86部署运行的通用字节码，匹配性能与开源5.4.2版本相比不劣化。

4）在arm部署运行的通用字节码，匹配性能与本机编译的字节码相比不劣化。
